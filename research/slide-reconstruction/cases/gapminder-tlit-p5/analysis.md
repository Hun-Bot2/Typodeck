# gapminder-tlit-p5 — Single-column explainer (G3 variant)

blue underlined URLs + footer. SINGLE column (vs tle-p5's flowed 2-col) —
same family, different density solution. Mustard headline, slate #364A50 body,
link blue #0000FF sampled. Neighbors: results table p4 before, license p6 after.

but lose underline (no underline style — recorded gap); bodies at 12.5pt (vs
tle-p5 13pt) to hold full text on one 16:9 slide — honest density adaptation.
