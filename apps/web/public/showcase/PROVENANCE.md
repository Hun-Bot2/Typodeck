# Showcase asset provenance (`apps/web/public/showcase/`)

Every file here is pipeline output, not hand-made. Two origins:

## 1. Verified decks (copies of `showcase/decks/`)

`is-swiss.*`, `dayjs-editorial.*`, `handbook-expressive.*` (`.pptx` + deck
`.json` + `.provenance.json`) are byte copies of the demo-evidence package
in `showcase/decks/` (branch `showcase/demo-evidence`, base `ff68b70`;
integrated at `b09865c`). Full method, pins, seeds, and independent checks
are recorded in `showcase/manifest.md` §§1–6:

- `is-swiss` — `sindresorhus/is` @ `e9c026c` (main), system `swiss`, seed
  `1143001754`, 12 slides / 46 text boxes / 1,332 editable chars.
- `dayjs-editorial` — `iamkun/dayjs` @ `436bde0` (dev), system `editorial`,
  seed `1713200736`, 12 slides / 46 text boxes / 1,987 editable chars.
- `handbook-expressive` — `microsoft/TypeScript-Handbook` @ `543d2df`
  (master), system `expressive`, seed `33113867`, 12 slides / 46 text boxes /
  1,909 editable chars.

Reproduce with the committed runner (repo root):

```sh
node showcase/run-deck.js --repo sindresorhus/is --system swiss \
  --purpose "Tool showcase: is" --lang en \
  --out showcase/decks/is-swiss.pptx --json showcase/decks/is-swiss.json
# (dayjs-editorial, handbook-expressive: see showcase/manifest.md §3)
```

Preview images for these three live in `apps/web/public/landing/`
(`*.filmstrip.png`); the showcase page references them there instead of
duplicating ~1 MB of PNGs. Their origin is documented in
`apps/web/public/landing/PROVENANCE.md`.

## 2. Experimental deck (generated in place)

`harborlight-document.*` was generated 2026-10-31 by the committed script
`apps/web/scripts/showcase-experimental.js` (idea mode, `document` system,
purpose `P01`, original idea text in `harborlight-document.idea.txt`):

- 6 slides / 24 text boxes / 1,267 editable chars, seed `1526367637`,
  validator OK. All 6 claims `ungrounded` (idea mode), captioned
  `unverified · illustrative` on the slides.
- Deterministic: re-running the script reproduces the deck JSON
  byte-for-byte (verified: identical JSON, same seed).
- `harborlight-document.filmstrip.png` is a headless-Chrome rasterization of
  the SlideView-faithful HTML from
  `apps/web/scripts/showcase-filmstrip.js` (geometry preview, not a PPTX
  rasterization — same caveat as the verified decks).

Reproduce (repo root, after `npm run build -w @typodeck/core`):

```sh
node apps/web/scripts/showcase-experimental.js
node apps/web/scripts/showcase-filmstrip.js  # HTML; rasterize per its header
```

## Policy

No third-party or copyrighted slide decks are presented as Typodeck output.
Everything on the showcase page was generated by the Typodeck pipeline from
the pinned source shown, and labeled `verified` (evidence-backed repo run),
`experimental` (renderable but non-production system), or `research`
(human-review material in `gallery/`, never presented as product output).
