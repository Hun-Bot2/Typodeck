# Peer Review — Korean Preview Card (`ko`)

Parent preview: `../preview.md` (selection metadata, palette, journal apparatus
— all apply). Korean override: `typography.md` in this folder.

## Korean preview rules

- Build exactly one title slide at 1920×1080, `lang="ko"`, fixed-stage model.
- Article title in Noto Serif KR 700, 86px, 1.16 leading, keep-all + balance.
- Runhead/kicker: Pretendard 700, NO caps/tracking on Korean; double-rule
  masthead unchanged.
- Abstract line (if shown): Noto Serif KR 500 upright, 1.65 leading.
- Citation tokens (`[1]`, `Fig. 1`) stay Latin, nowrap.
- Load: Noto Serif KR (Google Fonts) + Pretendard Variable (jsDelivr).
- Never place workflow text, slug, or template name on the slide.
