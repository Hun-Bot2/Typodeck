# Fika — Korean Preview Card (`ko`)

Parent preview: `../preview.md` (selection metadata, palette, pastel panels —
all apply). Korean override: `typography.md` in this folder.

## Korean preview rules

- Build exactly one title slide at 1920×1080, `lang="ko"`, fixed-stage model.
- Hero in Noto Serif KR 600, 80px, 1.2 leading, NO lowercase transform,
  keep-all + balance.
- Body/labels/chips in SUIT (400 body, 700 labels), 0 tracking, no caps on Korean.
- Pastel panels, radii, two-column airy rhythm unchanged.
- Data numerals stay Fraunces Latin.
- Load: Noto Serif KR (Google Fonts) + SUIT Variable (jsDelivr).
- Never place workflow text, slug, or template name on the slide.
