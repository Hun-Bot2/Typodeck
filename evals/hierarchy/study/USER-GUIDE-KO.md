# Typodeck 시각적 위계 평가 — 사용자 실험 가이드

25개 슬라이드, 1인 파일럿. 정답 맞히기가 아니라 보이는 그대로의 인상을 수집하는
평가입니다. 예상 소요: 슬라이드당 2~3분.

참고: S23·S24 두 케이스는 원본과 렌더링이 완전히 동일해서(의도 변형만 있고
화면은 바이트까지 같음) 평가에서 제외했습니다. 파일에는 모델용으로 보관됩니다.

## 1. 서버 실행

서버는 지금 실행 중이 아닙니다. 터미널 2개 명령으로 시작하세요.

```sh
cd /Users/jeonghun/Typodeck && npm run build -w @typodeck/core
cd apps/web && npx next dev --port 3100
```

`✓ Ready`가 뜨면 준비 완료. 종료는 해당 터미널에서 `Ctrl+C`.
(3000번 포트는 다른 프로세스가 사용 중이므로 3100번을 씁니다.)

## 2. 사이트 접속

브라우저에서 다음 주소를 여세요.

```text
http://localhost:3100/study
```

## 3. 평가 시작

평가자 이름이 `owner`인지 확인하고 파란색 **평가 시작** 버튼을 누르세요.

## 4. 첫 시선 선택

질문: **이 슬라이드를 처음 봤을 때 가장 먼저 눈에 들어온 요소는 무엇인가요?**

슬라이드 위 파란 점선 상자를 직접 클릭하세요. 아래 번호 목록에서
골라도 됩니다. 선택한 요소는 진하게 표시됩니다.

## 5. 중요도 순위 지정

질문: **어떤 요소가 가장 강조되어 보이나요? 중요해 보이는 순서대로 정렬해 주세요.**

위에서 아래로 중요해 보이는 순서입니다. 드래그 또는 키보드(↑/↓)로
순서를 바꾸고, 비슷해 보이면 동점(tie) 버튼으로 묶으세요.

## 6. Grouping 평가

질문: **서로 연결된 하나의 정보처럼 보이는 요소들을 선택해 주세요.**

덩어리로 보이는 요소들을 여러 개 클릭하세요. 화면의 예시를 참고하되,
정해진 답은 없습니다.

## 7. 문제점 표시

질문: **시각적으로 어색하거나 이해하기 어려운 부분이 있나요?**

해당하는 항목을 고르세요: 문제 없음 / 텍스트 잘림·오버플로 /
대비 부족 / 혼란스러운 강조 / 불명확한 그룹화 / 어려운 읽기 순서 /
열악한 간격·정렬 / 기타. 필요한 요소는 클릭으로 지정하고 의견을 적으세요.
그 아래 별도 칸에는 슬라이드가 전달하려는 핵심 메시지를 자유롭게 적으세요.

## 8. 다음 슬라이드 진행

질문: **이 판단에 얼마나 확신하나요?** (1~5, 디자인 점수가 아님)

오른쪽 아래 버튼으로 다음 슬라이드로 이동합니다. 상단에
**평가 N / 25**으로 진행률이 표시됩니다. 이전/다음으로 언제든
돌아가 수정할 수 있고, 새로고침해도 이어서 계속됩니다
(같은 이름으로 다시 시작하면 서버 저장본이 복원됩니다).

## 9. 평가 결과 저장 (25개 전부 완료 후)

답은 매 단계 서버에 자동 저장됩니다.

- 진행 중: `evals/hierarchy/study/annotations/owner.json`
- **응답 검토**에서 누락을 확인한 뒤 확정하면
  `evals/hierarchy/study/annotations/owner.final.<시각>.json` 생성
  (덮어쓰지 않고 시각별로 보존됩니다)

## 10. AI 비교 실행

확정 후 대시보드의 **평가 실행** 버튼을 누르세요. 텍스트 기반(A)과
레이아웃 기반(C) 평가가 실행되고, 이미지 기반(B/D)은 연결된
시각 모델이 없어 **NOT RUN**으로 표시됩니다(정상입니다).

## 11. 비교 결과 확인

대시보드는 케이스별 내 판단 vs AI 예측, 일치/불일치, 복구 전/후
(해당 시), 실행된 평가 항목과 미검증 가설을 보여줍니다.
단일 종합 점수는 없습니다. 불확실한 케이스는 따로 표시됩니다.

## 12. 결과 전달

다음 파일들을 공유하세요.

- `evals/hierarchy/study/annotations/owner.final.<시각>.json` (내 응답)
- `evals/hierarchy/study/results/owner.<시각>.json` (AI 비교 결과)
- 다운로드한 JSON/CSV 내보내기 파일 (해당 시)

주의: `test-`로 시작하는 이름의 응답은 연습용으로 분리 보관되며
결과에 합산되지 않습니다.
