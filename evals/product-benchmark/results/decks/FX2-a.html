Pipecheck

Pipecheck lints deployment pipeline files before they fail at 2 AM. It reads a 200line YAML workflow, checks 14 rules, and reports in about 2 seconds — as a CLI or as 1 GitHub PR comment.
Version 1.1.0 · Pipeline linter: 14 rules over YAML workflows, 2-second reports, PR comments.

Config

25 lines of YAML: enable/disable any of the 14 rules, set timeout bounds (5 to 60 minutes), pin the 3 allowed runner labels.
Strict mode turns the 5 consistency rules into errors.
1 command (pipecheck explain R07) prints the rationale for any rule.
