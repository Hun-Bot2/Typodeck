# Typo Pack Design Reference: 8-Bit Orbit (retired)

This internal note formerly preserved two user-supplied reference files as an
**internal architecture/design-study seed**:

- `typo-pack/templates/8-bit-orbit/preview.md` — small title-slide preview instructions and selection metadata.
- `typo-pack/templates/8-bit-orbit/design.md` — complete detailed visual system specification (verbatim from the provided attachment).

Canonical path note: the files arrived under the legacy
`bold-template-pack/` directory and were renamed as part of the Typo Pack
migration.

The files themselves were removed from the shipped pack because the engine
never reads them; the two-document contract they established — one selection
preview plus one full design document — is still reflected by the remaining
27 designs. Do not imply the original author granted redistribution rights;
do not republish the retired third-party reference unchanged without license
review and permission. Verbatim checksums are preserved in `SOURCE.md`.

These files did not provide a renderer implementation. See the TypoPPT agent
instructions for integration and verification requirements.
